# Beta releases

Khayt publishes **stable** and **beta** channels on GitHub:

| Channel | Example | Where |
|---------|---------|-------|
| **Stable** | `v2.3.3` | [Latest release](https://github.com/Alballaa/Khayt/releases/latest) |
| **Beta** | `v2.4.0-beta.1` | [Pre-releases](https://github.com/Alballaa/Khayt/releases) |

## Opt-in beta updates (stable installs)

From **v2.3.3**, stable installs can opt into beta builds:

**Settings → Data & Locale → Include beta pre-releases when checking for updates**

- **Off (default)** — only stable releases are offered.
- **On** — beta pre-releases appear in in-app update checks.

The preference is stored as `settings.betaUpdates` and synced to the updater on boot and save.

## Download beta manually

1. Open [GitHub Releases](https://github.com/Alballaa/Khayt/releases).
2. Filter **Pre-release** (or open a `v*-beta.*` tag).
3. Download the installer for your platform.
